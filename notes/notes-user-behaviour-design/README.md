# User behaviour design

**Principle:** people aim before they look. A control someone just used,
and is likely to use again, must stay where their hand left it.

Notes on designing around what people actually do with the pointer, the
keyboard and their eyes. One folder per topic, each with the rule, why it
works, the numbers and a way to check it.

| Topic | Rule |
| --- | --- |
| [Tab anchor](tab-anchor/) | Pin the edge your controls sit on, so tabs never move when the content under them changes height. Video, the CSS fix and a script that measures tab drift. |

## Install

npx skills add https://github.com/craftUI012/Skills/tree/main/notes/notes-user-behaviour-design
